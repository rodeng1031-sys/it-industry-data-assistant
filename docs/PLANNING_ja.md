# 企画書: IT Industry Data Assistant

## 1. プロジェクト名

**IT Industry Data Assistant**

## 2. 背景

IT/SI産業は、景気変動、公共・民間プロジェクトの発注サイクル、人材需要の変化に影響を受けやすい分野である。しかし、個別企業の売上データや求人データだけでは、産業全体の変化を継続的に把握することは難しい。

そこで本プロジェクトでは、公的統計であるサービス業生産指数と雇用行政統計を用いて、韓国IT/SI関連産業の月次推移、季節性、求人需要との関係を分析する。

## 3. 目的

本プロジェクトの目的は以下の通りである。

1. 韓国IT/SI関連産業の月次サービス活動の推移を把握する。
2. SI関連産業に特定月への集中傾向があるか確認する。
3. IT関連細分類産業ごとの季節性の違いを比較する。
4. IT職種の求人需要と産業活動指数の関係を確認する。
5. 単純な前年同月予測モデルを用いて、時系列の変化点や予測困難な時点を把握する。

## 4. 分析対象

### 4.1 産業データ

- データ: サービス業生産指数
- 出所: KOSIS / 韓国統計庁
- 周期: 月次
- 期間: 2017年1月 ~ 2026年8月
- 主な指標: 不変指数
- 比較指標: 経常指数

対象産業:

- 情報通信業
- ソフトウェア開発及び供給業
- コンピュータプログラミング、システム統合及び管理業
- 情報サービス業

### 4.2 求人需要データ

- データ: 職種別 求人・求職・就業現況（月次）
- 出所: 韓国雇用情報院 雇用行政統計
- 周期: 月次
- 期間: 2017年1月 ~ 2026年8月

分析用職種指標:

- `it_broad`: 情報通信関連の上位職種全体
- `software_developer`: ソフトウェア開発者関連職種

## 5. 分析質問

| 番号 | 質問 |
|---|---|
| Q1 | SI関連産業に3月集中傾向はあるか |
| Q2 | 長期的な生産指数は成長しているか。COVID-19参考期間に落ち込みはあるか |
| Q3 | IT関連細分類産業ごとに季節性は異なるか |
| Q4 | IT求人需要はSI関連生産指数と同じ方向に動くか。先行・遅行関係はあるか |
| Q5 | 前年同月値を使うSeasonal Naive予測はどの時点で大きく外れるか |

## 6. 分析方法

### 6.1 前処理

- KOSIS CSVをcp949で読み込む。
- 月次カラムをlong formatに変換する。
- 分析対象産業と指数種別を抽出する。
- 雇用行政統計のExcelファイルをOOXMLとして解析する。
- 職種分類変更に対応するため、2007/2018/2025分類の類似職種を接続する。
- 月次単位でサービス業生産指数と求人需要を結合する。

### 6.2 可視化

- 不変指数の長期推移と12か月移動平均
- 月別季節比率
- 経常指数と不変指数の比較
- 生産指数と求人需要の指数化比較
- ±6か月のラグ相関
- Seasonal Naive予測と誤差

### 6.3 評価指標

- 月別季節比率
- 季節比率の標準偏差
- 同月相関係数
- ラグ相関係数
- 絶対百分率誤差（APE）

## 8. 期待される効果

- 公的統計を用いてIT/SI産業の変化を客観的に把握できる。
- 季節性や長期トレンドを視覚的に確認できる。
- 求人需要と産業活動の関係を検討できる。
- 後続のAIデータアシスタントやダッシュボード開発に拡張しやすい。

## 9. 制約事項

1. サービス業生産指数は売上高そのものではなく、産業活動水準を示す指数である。
2. 職種分類が2007/2018/2025体系で変更されており、長期比較には注意が必要である。
3. 求人数 / 求職件数の比率は公式な求人倍率ではない。
4. COVID-19期間は参考期間として扱っており、因果関係を証明するものではない。
5. 原本データのライセンス確認前のため、CSV/XLS/XLSXファイルはGitに含めない。
